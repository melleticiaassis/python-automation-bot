# 🚀 Python Automation Bot

Projeto de automação desenvolvido com Python, Pandas e PyAutoGUI com foco na automatização do cadastro de produtos em um sistema web.

A automação realiza todo o processo automaticamente, desde a abertura do navegador até o preenchimento e envio das informações dos produtos utilizando uma base de dados em CSV.

---

# 🤖 Funcionalidades do Bot

✔ Abertura automática do navegador
✔ Login automatizado no sistema
✔ Leitura de base de dados CSV
✔ Manipulação de dados com Pandas
✔ Preenchimento automático de formulários
✔ Cadastro automatizado de produtos
✔ Execução contínua e padronizada do processo

# ⚠ Importante

As posições do mouse utilizadas na automação podem variar de acordo com a resolução do monitor.

Utilize o arquivo `pegar_posicao.py` para identificar corretamente as coordenadas necessárias para os cliques.

Durante a execução da automação, evite movimentar o mouse ou utilizar o computador.
